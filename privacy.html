The Loot Table

Privacy Policy

Effective 3 September 2026

This policy covers two things: this website, and the private publishing tool called The Loot Table Podcast that the show's owner uses to post episodes to the show's own social media accounts on TikTok, YouTube, and Instagram.

This website

The website is a static page. It sets no cookies, runs no analytics, and collects no personal information from visitors. Requests are served by GitHub Pages, whose own handling of server logs is described in GitHub's privacy statement.

The publishing tool

The publishing tool is used by one person, the owner of the show, to upload finished videos to accounts the owner controls. It is not offered to the public and no one else can sign in to it.

When the owner authorizes the tool with a platform (for example, TikTok's Login Kit), the platform issues access tokens. Those tokens are stored only on the owner's own computer and are used solely to upload videos and read the upload status. The tool does not read messages, followers, comments, or any other account data, and does not access any account other than the owner's.

The tool sends video files, titles, descriptions, and hashtags to the platform being posted to. It does not send that content, or any tokens, to any other party.

Data about other people

Neither the website nor the tool collects, stores, or processes personal data about viewers, followers, commenters, or anyone other than the owner.

Retention and deletion

Tokens stay on the owner's computer until revoked or deleted. Access can be revoked at any time from the connected-apps settings of the platform concerned, which invalidates the stored tokens.

Changes

If this policy changes, the new version is published at this address with a new effective date.
